# Локальная копия isipto.ru

Главная: http://localhost:3000/

Админка MODX: http://localhost:3000/manager/

Запуск из этой папки: `docker compose up -d`.
После изменения Dockerfile: `docker compose up -d --build`.
Остановка без удаления базы: `docker compose stop`.

Сайт работает на MODX Revolution, локальном Apache/PHP 7.4 с GD и MySQL 5.7.
В HTTP-ответе isipto.ru от 22.10.2026 указан PHP/7.3.33; по SSH запускается
другой обработчик — PHP 5.6.40 CLI. Исходный index.php содержит оператор `??`
и несовместим с PHP 5.6. Перед публикацией проверять PHP веб-сайта; не менять
его версию ради новой главной. Подробности: ../docs/hosting-audit-20261022.md.

Локальная база хранится в Docker-томе `db-data`. Команда `docker compose down -v`
удаляет этот том; её нельзя использовать для обычной остановки.
Первоначальный дамп находится в `database/modx.sql.gz` и исключён из Git.
Серверная конфигурация сохранена в `core/config/config.inc.php.production`.

В локальных `config.core.php` исправлены пути к ядру, а в `.htaccess`
только для localhost переписываются ссылки на основной домен.
Эти настройки относятся к локальному окружению и не предназначены для
прямой загрузки поверх конфигурации хостинга.

Снимок не включает сессии, временные кэши, старые архивы развёртывания
и каталог st, исключённый по указанию владельца как неиспользуемый A/B-тест.

Проверка после исправления: 85 страниц из меню совпадают с доменом
по HTTP-статусу и заголовкам H1/H2; все 42 ресурса главной доступны.
Форма входа MODX загружается; вход под учётной записью и отправка заявок
в CRM в ходе проверки не выполнялись.
