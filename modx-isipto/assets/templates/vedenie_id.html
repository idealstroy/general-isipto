Что делать с полученным реестром документации?

После подписания папок исполнительной документации у всех участников строительства, мы передаем их нашему заказчику по акту приема-передачи с реестром исполнительной документации.

Для вас реестр сданной документации является исходным документом для заполнения актов КС-2, КС-3. Реестр составляется на каждую папку исполнительной документации и содержит только подписанную документацию.
