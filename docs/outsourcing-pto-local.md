## Резервная копия и откат

Папка `_backups/outsourcing-promotion-local-2026-10-27/` находится вне корня сайта и исключена из Git. Содержит прежний шаблон, полный снимок тестовой папки, исходную запись ресурса/шаблона и связи TV, контрольные суммы БД и отчёт проверки. Это резервная копия изменяемой страницы и её зависимостей, не полный дамп БД.

Для локального отката: `node deployment/homepage/run-local-php.mjs deployment/homepage/rollback-outsourcing-local.php`. Скрипт проверяет, что новым шаблоном пользуется только целевой ресурс, возвращает шаблон 36 и удаляет только созданные для этой публикации записи шаблона, его TV-связей и трёх чанков. Файлы не удаляет. Перед откатом после последующих правок нужно дополнительно сохранить текущую версию.

`promote-outsourcing-local.php` — контролируемая регистрация этих постоянных файлов после восстановления старой локальной БД, не скрипт для хостинга. При повторном запуске на уже обновлённой странице отказывает без изменения данных.
