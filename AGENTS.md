# Правила дизайн-системы isipto.ru

- Заголовки и слоганы нельзя окрашивать в красный цвет. Использовать основной цвет текста из действующих стилей сайта.
- Размер шрифта акцентного посыла или слогана не должен превышать размер H2. Для посыла внутри блока использовать существующий шаблон подзаголовка.
- Формы блоков, цвета, типографику и кнопки брать из существующих шаблонов и общих CSS сайта. Размеры кнопок наследовать от исходного компонента.
- Внутренние кнопки-ссылки должны контрастировать с фоном блока: на белом фоне использовать штатную серую кнопку `seraya_knopka`, на сером фоне — штатную белую `belaya_knopka`. Не создавать для этого новые стили кнопок. Конверсионные кнопки остаются красными по отдельному правилу.
- Оранжевые акценты не использовать: маркеры списков, иконки и элементы иллюстраций выполнять в фирменном красном `#E03B32`, если они требуют акцентного цвета.
- Конверсионную кнопку брать из главного экрана как есть: `btn btn_first-screen krasnya_knopka btn-modal`, с текстом «Получить расчёт» она открывает штатную форму заявки во всплывающем окне Fancybox.
- При замене оформления удалять старый неиспользуемый код и стили.
- Для конверсионных кнопок заявки использовать существующий попап `#form_up` из `footer_new` со штатной формой `form_tpl1`, как на домене. Не создавать отдельную форму попапа и не подменять её контентным блоком страницы. Кнопки-ссылки на страницы этим правилом не изменять.
